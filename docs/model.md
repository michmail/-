# Математическая модель калькулятора букета

## Переменные
- `x1` — тип цветов (1, 2, 3)
- `x2` — количество цветов (целое, >0)
- `x3` — тип упаковки (1, 2, 3)
- `x4` — доставка (0 или 1)
- `x5` — открытка (0 или 1)

## Целевая функция (стоимость)
C = (price_flower(x1) × x2) + price_packaging(x3) + 300×x4 + 50×x5

## Ограничения
- `x2 ≥ 1`
- Скидка применяется при x2 > 50: C = C × 0.9
- Скидка применяется при x2 > 100: C = C × 0.85

## Оптимизация
При фиксированном бюджете B можно подобрать максимальное количество цветов:
x2_max = (B - price_packaging(x3) - 300×x4 - 50×x5) / price_flower(x1)
